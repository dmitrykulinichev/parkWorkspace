## Раннє попередження про авто без графіку на найближчі дні

Раніше дашборд персоналу в мобільному застосунку показував лише авто, які
вже прямо зараз без водія. Додали новий сервіс `VehicleScheduleRiskService`,
який окремо визначає авто, що ЗАРАЗ мають водія, але для яких не заплановано
графік (робочу зміну) на завтра або післязавтра — рання ознака простою, щоб
адміністратор встиг знайти підміну заздалегідь, а не постфактум.

Дані віддаються у `/staff/dashboard-summary` (два нові лічильники) і в
новому ендпоінті `/staff/vehicles/schedule-risk` (списки id авто по групах
"завтра"/"післязавтра").

## Новий ендпоінт графіку для персоналу (мобільний застосунок)

Персонал у мобільному застосунку раніше не мав доступу до графіку водіїв
узагалі — лише сам водій бачив свій особистий графік. Додали
`DriverStaffScheduleController::index()` (`GET /staff/schedule?from=&to=`) —
той самий графік (`DriverScheduleSlot`), що на веб-сторінці "Графік", але
лише для перегляду: усі зміни парку з водієм і автомобілем, без можливості
редагування (drag&drop/CRUD є лише у веб-кабінеті). Один запит — один парк,
за тим самим принципом, що вже працює для особистого графіка водія; якщо
персонал має доступ до кількох парків, мобільний клієнт сам звертається по
черзі до кожного.

Мобільна сторінка показує графік таблицею (авто рядками, дати стовпцями),
де рядки мають бути всі автомобілі парку, навіть без жодного слота — тому
додали ще `DriverStaffScheduleController::options()`
(`GET /staff/schedule/options?park_ids[]=...`): один легкий запит, що
одразу віддає список авто з УСІХ доступних персоналу парків, згрупований
по парку (на відміну від слотів, тут не потрібно ганяти по одному запиту
на кожен парк — це просто довідник). Доступ до парку звіряється з
`User::accessibleParkIds()`, щоб клієнт не міг запитати чужий парк.

## Сигнал "пробіг не передано сьогодні"

Додали `VehicleScheduleRiskService`-подібний сервіс `VehicleMileageComplianceService`:
визначає авто, які зараз мають водія, але для яких ще не зафіксовано жодного
запису пробігу сьогодні (байдуже яким джерелом — додаток, бот, веб,
телеграм, призначення). Лічильник — у `/staff/dashboard-summary`, повний
список id — у новому `GET /staff/vehicles/missing-mileage-today`.
