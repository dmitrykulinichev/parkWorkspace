# Скріни для документації

Скріни застосунку водія й кабінету — без рамок, повного розміру, за розділами. Звідси беремо картинки для
розділу документації на лендінгу (`/docs`) і для статей блогу (рамки й колажі статей — `workspace/blog`).

- `app-driver/` — застосунок водія, простий режим (емулятор, 1080×2400, статус-бар 12:00).
- `cabinet/` — веб-кабінет парку (Chrome, 1440 px, ×2).

Дані — тестовий парк «Київ», водій Петренко Олександр, авто KA 9001 AR (Toyota Camry). Таксі не знімаємо.
