# Посібники (документація v2)

_Створено: 2026-11-05._

Мета — **навчити персонал парку й водіїв працювати з продуктом**: мало сторінок, які ведуть людину через її
реальну роботу; не довідник по кожному екрану. Маркетинг, нові можливості й розвиток продукту — у блозі.
Публікується на лендінгу в `/docs` (`landing/www/content/docs2`), потім трьома мовами (`plans/landing-i18n-plan.md`, етап 2).

Постійний документ продукту: **реєстр** розділів і сторінок, **мозок** (рішення й правила), **руки** (чим робимо).
Хід поточної роботи (план, лог сесії, журнал рук) — у папці задачі за `CLAUDE.md` («сесія — мозок — руки»):
`workspace/tasks/2026-11-05-docs-v2-driver/`.

`3 Залито` (користувач дивиться готовий варіант) → `4 Погоджено` → `5 Відео` (ролик у своє місце). У реєстрі — остання завершена стадія.

- **05.11.2026.** Документацію одразу супроводжуємо живими скрінами: чернетка без скрінів не йде на розбір.

## Правила

**Зміст**
1. Сторінка — одна ситуація з роботи людини («Як почати», «Зміна»), а не один екран застосунку. (05.11)
2. Лише практичне: що зробити й що станеться. Без реклами й без «чому це важливо». (05.11)
3. Кожне твердження звірене з поточною збіркою чи кабінетом; у реєстрі — версія, з якою звіряли. (05.11)
4. Пишемо для людини без технічних знань: без жаргону (API, синхронізація черги, CRUD тощо). (05.11)

**Форма**
5. Кроки нумеровані, одна дія на крок. Назви кнопок і пунктів — точно як в інтерфейсі, у «лапках». (05.11)
6. Звертання на «ви», короткі речення; стиль — людський, без «—» і «–» (як у блозі). (05.11)
7. Сторінка — до одного-двох екранів телефона тексту: водій читає з телефона. (05.11)

**Скріни й відео**
8. Скріни — тестовий парк «Київ», тестові водії (Петренко й ін.); рецензенти сторів і живі парки — не в кадрі. (05.11)
9. Скріни живі — зняті з поточної збірки під час написання сторінки, через `capture.mjs` (реєстр
   `landing/www/content/screens.json`), одразу трьома мовами. (05.11)
10. Відео доповнює текст: сторінка зрозуміла й без відео. Місце для ролика — у розділі тієї дії, яку він показує. (05.11)
11. Скрін — лише там, де без нього незрозуміло, куди натиснути (на В1 — три). (05.11)
12. Якщо до мети веде кілька шляхів (самостійна реєстрація чи водій, якого вже додав парк), сторінка починається з
    того, як обрати свій. (05.11)
