# Лендінг: мультимовність (uk / en / ru)

_Створено: 2026-10-31. Статус: основу закладено (2026-10-31), далі — тексти сторінок._

Як влаштовано й правила — `landing/www/app/I18n/README.md`.

Лендінг (`landing/www`, Leaf PHP + Blade) зараз лише українською: `<html lang="uk">`, тексти прямо в
Blade і в масивах контролерів (напр. `FeaturesController`), у формах — ще й у JavaScript. Мультимовність
кабінету й бекенду (`workspace/plans/i18n-plan.md`) лендінг не охоплювала.

## Рішення (погоджено 2026-10-31)

- Мови: **українська (основна), англійська, російська**. Російську окремо не виділяємо — одна з мов.
- Етап 1: інфраструктура + основні сторінки. Документація, блог, юридичні тексти — наступні етапи.

## Схема

1. **Адреси.** Українська — на корені (`/features`), інші — з префіксом (`/en/features`, `/ru/features`).
   Чинні адреси й SEO не змінюються. Без автоперенаправлення за мовою браузера (шкодить індексації) —
   лише перемикач у шапці.
2. **Мовний модуль** — окремо, `app/I18n/`:
   - `Locale` — підтримувані мови, поточна (з префікса адреси), основна `uk`;
   - `Translator` — словники `lang/{uk,en,ru}.php` (вкладені ключі), `t('features.title')`; немає перекладу
     → українська (ніколи не порожньо);
   - помічники для Blade: `t()`, `lurl('/pricing')` (адреса з поточним префіксом), `alternates()` (адреса
     сторінки іншими мовами — для перемикача й `hreflang`).
3. **Маршрути** (`app/routes.php`): ті самі сторінки реєструються для кореня й для `/en`, `/ru`; мова
   ставиться до контролера. API (`/api/*`) — без префікса, мову отримує з запиту.
4. **Тексти**: з Blade і контролерів — у словники. Тексти для JS форм — у словнику, передаються в
   сторінку JSON-ом (без дублювання в JS).
5. **SEO**: `<html lang>`, `hreflang` для всіх мов + `x-default`, `og:locale`, canonical з мовою; мапа сайту
   — адреси всіх мов з `xhtml:link` альтернативами.
6. **Форми заявки й реєстрації парку**: мову передаємо в СААС (`X-Locale`, як застосунок) — новий
   користувач кабінету отримує мову, якою реєструвався; повідомлення API — його мовою.
7. **Контент наступних етапів**: `content/pages/{en,ru}/…`, `content/docs2/{en,ru}/…` з поверненням до
   української, якщо перекладу немає; блог — поле мови в статей СААС, розділ мовою показує лише свої статті.
