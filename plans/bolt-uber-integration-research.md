# Bolt і Uber: чи можна інтегрувати без реального парку (дослідження 17.11.2026)

## Bolt — Fleet API 2.0
- Документація публічна: https://developer.bolt.eu/fleet-integration/main/ (сторінка рендериться JS — читати в браузері).
- Доступ: OAuth 2.0 Client Credentials (client_id + secret → токен, scope `fleet-integration:api`). Ключі генерує
  власник флоту в Bolt Fleet Portal (за сторонніми джерелами; офіційної сторінки про це не знайшли).
- Усі ендпоінти — POST на шлюзі `fleetIntegration/v2/...`; усі, крім «Get companies», потребують `company_id`,
  доступного ключу. Підтверджено: `getDrivers`, `getDriverUuids`, фільтри за `driver_uuids` / `vehicle_uuids`.
  Замовлення (`getFleetOrders`) — лише зі стороннього коду, в офіційних доках не підтверджено.
- Пісочниці не знайшли. Отже: ключ = справжній флот.

## Uber — Vehicle Suppliers / Supplier Performance Data API
- Документація: https://developer.uber.com/docs/vehicles/references/api/v1/supplier-performance-data/overview —
  з позначкою «confidentially shared… under development», тобто обмежений доступ.
- Що є: організації (`get-orgs`), продуктивність водіїв/авто (години онлайн, поїздки, заробіток), виплати водіям
  лише за останні 24 год, транзакції, водії (статус, геолокація), керування авто.
- Доступ: scopes `vehicle_suppliers.*`, `supplier.fleet.*`, client credentials; процесу отримання доступу в доках нема —
  через програму партнерів Uber. Пісочниця `sandbox-api.uber.com` згадується, але FAQ окремих ендпоінтів пишуть,
  що sandbox не підтримується.

## Ринок
- Сторонні CRM (напр. MyTaxiCRM) заявляють інтеграції з Uber і Bolt — отже доступ флотам реально видають.
- 2026-2027: закон про цифрові платформи (реєстрація з листопада 2026, звітність з 01.01.2027) — платформи
  ідентифікують користувачів і звітують податковій; може вплинути на дані й вимоги до CRM.

## Висновок
Без справжнього флоту: можна спроєктувати спільний шар агрегатора і зробити демо-імітацію Bolt за доками.
Справжня інтеграція і звірка грошей — лише з пілотним парком, що дасть свої ключі Bolt (найпростіше) чи Uber
(доступ через Uber, довше й непрогнозовано). Почати з Bolt.
