# Changelog маркетингу — правила ведення (для агентів)

Накопичувальний журнал того, що зроблено в роботі з лідами g24: пошук клієнтів, база, контакти, дослідження.
Ведеться щодня, по факту виконаної роботи. Детальні цифри прогонів — у `prospecting/sources.md` і `methods/*/method.md`;
тут — коротко «що зробили, що отримали, що вирішили», щоб за тиждень можна було зрозуміти хід роботи без читання CSV.

## Структура
- Кожен день — папка `YYYY-MM-DD/`. Усередині — лише файли напрямів, де сьогодні справді щось змінилось:
  - `prospecting.md` — пошук лідів: нові джерела/методи, прогони, скільки додано, що відсіяно;
  - `outreach.md` — контакти з лідами: кому писали/дзвонили, відповіді, результати, зміни стадій;
  - `registry.md` — база й інструменти: структура CSV, скрипти, генеровані файли (REGISTRY.md, KARTA.md, BOLT.md…), виправлення даних;
  - `research.md` — дослідження ринку: конкуренти, спілки, партнерства (Uklon, Bolt), продуктові ідеї й рішення власника.
- Порожніх файлів не створювати. Кілька сесій того самого дня — дописувати в наявні файли.

## Формат запису
```
## Короткий заголовок (що зроблено)

2–6 речень: що і навіщо, результат у цифрах, де лежить (шлях), що вирішили / що далі.
```
Пишемо українською, для людини, а не для коду. Імена файлів — у бектиках. Рішення власника g24 позначаємо «Рішення власника:».
