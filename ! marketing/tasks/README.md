# Поточні задачі (роботи з лідами)

Тут лежать задачі, які треба **зробити руками** (власнику g24), разом з усім потрібним для виконання: кому, куди, готовий текст.
Щоб нічого не губилося в чаті.

## Правила
- Одна задача = один файл `YYYY-MM-DD_<коротко>.md` (дата створення). Зверху — статус і що зробити.
- Статуси: `відкрита` → `зроблена` (або `скасована`). Зроблену переносимо в `done/`.
- Задача — це лише «що зробити зараз». Факти (хто, телефон, історія) живуть у реєстрі (`registry/clients.csv`, `contacts.csv`),
  результат дій — записується через `registry/log_contact.py` і в `changelog/`.
- Список нижче оновлюємо при кожній зміні.
