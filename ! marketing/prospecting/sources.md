# Пошук клієнтів: джерела і критерії

## Критерії ліда (усі обов'язкові для стадії «перевірено»)
1. Посилання на **конкретне** оголошення чи пост, а не на сторінку пошуку.
2. Телефон або прямий канал власника (Viber/Telegram/чат OLX).
3. Ознаки малого парку: ФОП або власник пише від себе, «працюю з водіями особисто», 1–10 авто в оголошеннях, немає офісу чи HR.
4. Немає в реєстрі: перевіряємо дубль за `ключ_джерела` (напр. `olx:<user_id>`), телефоном і url; історія розглянутих — `registry/seen.csv`.

Відсіюємо: великі парки з офісом і менеджерами, агрегатори, рекрутингові агенції, «підключення до Uklon/Bolt» без власних авто.

## Джерела
| джерело | що шукати | примітка |
|---|---|---|
| OLX Робота | «водій таксі», «на авто компанії», Київ | власники часто пишуть від себе |
| OLX Авто / прокат | «оренда під таксі», «авто під викуп» | ✅ оформлено як метод `olx-prokat-avto` |
| Work.ua | «водій таксі», Київ + обл. центри | ✅ оформлено як метод `workua-vodiy-taksi` |
| Robota.ua | «водій таксі», Київ + обл. центри | ✅ оформлено як метод `robotaua-vodiy-taksi` |
| Jooble | вакансії водія таксі | агрегатор, переважно дублює Work/Robota |
| Telegram | канали парків, групи й дошки «оренда авто під таксі» | ✅ метод `telegram-orenda` |
| Facebook-групи | групи таксі/Uklon/Bolt, оренда під таксі | ✅ метод `facebook-groups` (слабке джерело) |
| СТО, ГБО-сервіси, партнери агрегаторів | вихід на кількох власників одразу | ще не перевірено |
