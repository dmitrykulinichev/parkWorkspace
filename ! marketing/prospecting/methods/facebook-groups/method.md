# Метод: Facebook — групи таксі / Uklon / Bolt / Uber і пости власників

| | |
|---|---|
| Джерело | facebook.com, пошук груп + стрічки відкритих груп (окремий робочий акаунт власника g24) |
| Гіпотеза | Власники пишуть «здам авто під таксі» в групах водіїв і групах оренди |
| Версія | 1.0 (2026-11-17); `read_fb.js` 1.1 — розкриває «See more» |
| Файли | `discover_fb.js` (пошук груп), `places.py` (відбір → `facebook_places.csv`), `read_fb.js` (читання постів); злиття постів — спільний `../telegram-orenda/merge_groups.py --site facebook` |
| Сирі дані | `_raw/<дата>_facebook-discover.json`, `_raw/<дата>_facebook-posts.json` |

## Як працює
1. **Пошук груп.** У полі пошуку Facebook вводимо запит (SPA-перехід, без перезавантаження, тож стан у `window` живе),
   відкриваємо фільтр «Групи», прокручуємо 4 рази, збираємо картки: id, назва, доступ (public/private), учасники, активність.
   ⚠️ Перехід через `navigate`/посилання перезавантажує сторінку, і накопичене в пам'яті й `localStorage` губиться (перевірено).
   Запити (45): загальні («оренда авто під таксі», «автопарк таксі», «водії таксі», «оренда авто uklon bolt»…) +
   «оренда авто таксі <22 міста>» + «аренда авто такси <5 міст рос.>» + «водії таксі <6 міст>».
2. **Відбір** (`places.py`): лише групи про **парки й таксі** (таксі/Uklon/Bolt/Uber/автопарк/«під викуп»). Відкидаємо продаж авто,
   скупку («автовикуп»), вантажне таксі, Молдову та інші країни. Загальна «оренда авто» без таксі не потрібна (рішення власника g24).
3. **Пости** (`read_fb.js`): для кожної відкритої групи відкриваємо сторінку, прокручуємо 15–20 разів і накопичуємо пости
   (автор, uid у групі, текст) у `sessionStorage` (він переживає переходи між групами). **Тільки читання**: не вступаємо, не коментуємо.
4. **Злиття**: `merge_groups.py --site facebook`. Оголошення = оренда/здам/викуп + ціна або телефон, але НЕ попит
   («куплю/візьму/шукаю») і НЕ іноземне (злоті, крони, лв, євро). Автор = телефон → @контакт → `fbu:<uid>`.

## Обмеження та висновок першого прогону
- Пошук груп у Facebook дуже «шумний»: з 1 649 знайдених груп релевантних лише 22 (19 відкритих), решта — продаж авто.
- У групах водіїв переважають балачки й попит («куплю акаунт Uklon»), а в групах оренди повно іноземних (PL, BG, CZ).
- У прогоні 1.0 текст постів обрізався на «See more», тож частина оголошень (напр. «Avto Arenda Alex», Київ, оренда з викупом,
  t.me/AutoArenda_Alex) не розпізналась. У `read_fb.js` 1.1 це виправлено.
- **Висновок:** Facebook — слабке джерело для нашого сегмента (3 ліди з 259 постів, 1 цільовий). Повторювати рідко.
