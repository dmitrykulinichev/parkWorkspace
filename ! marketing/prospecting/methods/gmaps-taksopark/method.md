# Метод: Google Maps — таксопарки й оренда авто під таксі по містах

| | |
|---|---|
| Джерело | Google Карти (https://www.google.com/maps/?hl=uk), публічна видача пошуку, без логіна |
| Гіпотеза | Парки з офісом чи майданчиком позначені на Картах: там є телефон, адреса, сайт і відгуки (≈ розмір і репутація) |
| Версія | 1.0 (2026-11-17) |
| Файли | `collector.js` (збір у браузері), `merge.py` (злиття в реєстр) |
| Сирі дані | `prospecting/_raw/<YYYY-MM-DD>_gmaps-taksopark.json` |

## Як працює
1. Для кожного запиту `таксопарк <місто>` і `оренда авто під таксі <місто>` (22 міста = 44 запити) скрипт вводить текст
   у поле пошуку Карт (SPA, без перезавантаження), прокручує список результатів до «кінця списку» (≤ 25 прокручувань)
   і збирає картки: назва, place-id (з посилання `/maps/place/…!1s<id>`), рейтинг (к-сть відгуків), категорія, адреса, телефон, сайт.
2. **Злиття** (`merge.py`): вантажне таксі й перевезення — лише в `seen`. Решта — у реєстр:
   - **парк** (у назві автопарк/таксопарк/park/оренда/«робота водієм»/партнер): A, якщо ≤ 30 відгуків, B — якщо більше;
   - **служба таксі** (диспетчерська без ознак парку) і **офіси агрегаторів** (Uklon, Bolt, Uber, OnTaxi, Opti) — C, орієнтир;
   - склейка: телефон → назва в тому ж місті; уже відомим дописуємо `Google Maps (місто)` у `де_рекламується`.

## Як відтворити
1. Відкрити https://www.google.com/maps/?hl=uk у Chrome, виконати `collector.js` у консолі → `g24gm.start()` (≈ 20–25 хв).
2. `g24gm.status()` до `done: true` → `g24gm.stage()` → Ctrl+C →
   `Get-Clipboard -Raw | Out-File -Encoding utf8 prospecting/_raw/<YYYY-MM-DD>_gmaps-taksopark.json`.
3. `python -I prospecting/methods/gmaps-taksopark/merge.py <файл> --dry-run`, потім без `--dry-run`.

## Обмеження
- Google показує до ~120 місць на запит; у Києві список може бути неповним.
- Тип «парк чи служба таксі» визначається за назвою, тому можливі помилки. Багато малих парків на Картах позначені як
  «Служба таксі».
- Кількість відгуків — лише грубий проксі розміру.
- Телефон у картці видачі є не завжди (інколи лише в деталях місця, які не відкриваємо).
- Якщо результат один, Google одразу відкриває картку місця замість списку («no list» у лозі). `collector.js` уже збирає й таку
  картку. Повтор через поле пошуку в тому самому циклі не спрацював (пошук не запускався, і зібрався старий список), тому такі
  запити добираємо прямими URL `https://www.google.com/maps/search/<запит>?hl=uk`.
- Запит «оренда авто під таксі» видає переважно звичайний прокат (155 з 296): він іде лише в `seen`.
