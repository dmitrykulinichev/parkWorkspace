## Шаблон нового методу
Папка `methods/<назва>/` з такими файлами:
- `method.md`: обов'язкові розділи
  1. шапка: джерело, гіпотеза (чому тут наші клієнти), версія, дата;
  2. **Як працює**: кроки алгоритму, точні URL/запити/фільтри;
  3. **Як відтворити**: покроково, з командами;
  4. **Правила відбору**: що вважаємо лідом, пріоритети;
  5. **Обмеження**: що метод пропускає, де помиляється;
  6. **Історія прогонів**: таблиця дата / параметри / скільки знайдено / скільки додано / файл сирих даних.
- код збору (`collector.*`), якщо збір автоматизований; для ручного методу — чек-лист у `method.md`;
- `merge.py` або опис, як результат потрапляє в `registry/clients.csv`.

Правила:
- Сирі вивантаження зберігаються в `prospecting/_raw/<YYYY-MM-DD>_<метод>.json|csv` і не редагуються.
- Кожен лід у реєстрі має `джерело` і, якщо можливо, стабільний `ключ_джерела` (наприклад `olx:<user_id>`),
  щоб повторні прогони не створювали дублів.
- Змінили алгоритм → піднімаємо версію в `method.md` і коротко пишемо, що змінилось.
- Ідеї нових джерел, ще не оформлені в метод, ведемо в беклозі в `prospecting/sources.md`.
