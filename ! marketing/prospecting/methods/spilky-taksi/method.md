2. **Сайти**: utma.org.ua (контакти, новини, дати), forum.taxiservice.com.ua (розділи, дата останньої активності).
   WebFetch тут повертає 403, тому читаємо в Chrome. Taxoport.com у Chrome не відкрився (повертає на попередню сторінку).
3. **Telegram**: скрипт `../telegram-orenda/discover.js` з власним списком запитів (`g24tg.start(Q)`, 42 запити, список нижче).

4. **Реєстр**: картка Opendatabot (без логіна дає 5 безкоштовних переглядів, контакти лише після реєстрації; ми не реєструвались).

## Висновок першого прогону
- **В Україні немає живого об'єднання власників автопарків Uklon/Bolt.** На запити «власники автопарків», «партнери Uklon/Bolt»
  тощо Telegram нічого не знаходить. Схожий чат «Автопарки чат 🇵🇱» (@Park_pl, 120 учасників) — про Польщу.
- Старі організації (УТМА, ПСТУ, «Таксі столиці», «Львівське таксі») — це ліцензовані перевізники й диспетчерські епохи до
  агрегаторів, і вони налаштовані проти Uklon/Bolt. Як канал до нашого сегмента вони не працюють, лише як орієнтир і GR.
- Більшість «союзів/профсоюзов таксистов» у Telegram — російські (Хабаровськ, Сочі, Волгоград…): відкинуто.
- **Корисне:**
  - **Uklon Fleets** (@uklon_fleets_ukraine) — відділ Uklon по роботі з автопарками; потенційний партнерський канал для g24;
  - **конкуренти й суміжні сервіси для парків**: SkyTaxi (вебпанель для власників автопарків), Lito.pro, U-Drivers, Taxion,
    програми для автопарків в Aris-Taxi і 571.
- Нових клієнтів-лідів метод не дав, тому реєстр клієнтів не змінено.

## Як відтворити
1. Вебпошук за запитами з п.1. Організації вносимо в `orgs.csv` (тип, контакти, керівник, активність, роль для g24).
2. web.telegram.org/k → один раз клацнути в поле пошуку → виконати `../telegram-orenda/discover.js` → `g24tg.start(Q)`
   зі списком вище → `g24tg.stage()` → клацнути в textarea → Ctrl+A, Ctrl+C →
   `Get-Clipboard -Raw` у `_raw/<дата>_spilky-telegram-discover.json`.
   Вкладка Telegram має бути активною, бо у фоні таймери гальмують.
3. Вибрати українські чати → `_raw/<дата>_spilky-telegram-subset.json` →
   `python -I prospecting/methods/telegram-orenda/parse_tme.py <subset> _raw/<дата>_spilky-telegram-tme.json`.

## Обмеження
- Глобальний пошук Telegram шукає лише за назвою та username чату, тож на українські запити видача майже порожня.
- Контакти організацій з реєстру (Opendatabot) закриті без реєстрації.
- Viber-спільноти (там багато водіїв) не перевіряли: веб-версії немає, лише вручну.
