# Метод: OLX «Робота» — вакансії водіїв таксі

| | |
|---|---|
| Джерело | OLX, розділ «Робота» (category_id = 6), публічний JSON-API сайту `/api/v1/offers/` у браузері (без логіна) |
| Гіпотеза | Малі парки, які беруть водіїв «на відсоток» (а не здають авто в оренду), шукають їх на OLX «Робота». Це інший розділ, ніж «Прокат авто» (метод olx-prokat-avto) |
| Версія | 1.0 (2026-11-18) |
| Файли | `collector.js` (збір у браузері), `merge.py` (злиття) |
| Сирі дані | `_raw/<дата>_olx-robota-taksi.json` |

## Як працює
1. `collector.js` для кожного запиту (`таксі`, `uklon`, `bolt`, `uber`, `водій на авто компанії`, `автопарк`) гортає
   `/api/v1/offers/?category_id=6&query=…` (до 1000 на запит, по 50, пауза 0,8 с), лишає вакансії, де в назві чи тексті
   є таксі/Uklon/Bolt/Uber/автопарк. Для кожного роботодавця бере `/api/v1/offers/?user_id=` (усього оголошень, вакансій, прокату).
   Телефон за кнопкою не відкриваємо, але беремо номери з тексту вакансії.
2. `merge.py`: роботодавець = `olx:<user_id>` (той самий ключ, що в olx-prokat-avto). Правила — у docstring:
   резюме / вантажне / автобус / закордон → лише seen; > 10 вакансій або > 15 прокатів чи агенція → C;
   1–3 таксі-вакансії з ознаками власного парку → A; решта → B. Уже відомим дописуємо «OLX робота (місто)».

## Як відтворити
1. Відкрити https://www.olx.ua/uk/rabota/ у Chrome, виконати `collector.js` → `g24olxj.start()` (≈ 10 хв).
2. `g24olxj.status()` до `done: true` → `g24olxj.stage()` → клацнути в textarea → Ctrl+A, Ctrl+C →
   `Get-Clipboard -Raw` у `prospecting/_raw/<YYYY-MM-DD>_olx-robota-taksi.json` (UTF-8 без BOM).
3. `python -I prospecting/methods/olx-robota-taksi/merge.py <файл> --dry-run`, потім без `--dry-run`.

## Обмеження
- Телефони OLX маскує й у тексті вакансій: у прогоні 2026-11-18 номер знайшовся лише у 2 з 323 нових. Основний канал — чат OLX.
- Пошук OLX за словом повертає й нерелевантне (прокат, послуги); фільтр за словами таксі/Uklon/Bolt/Uber/автопарк.
- Ім'я роботодавця на OLX — часто лише ім'я людини («Андрій»), тож склейка з іншими джерелами — за ключем і телефоном.
- Розмір парку не видно (лише к-сть оголошень прокату в профілі, якщо є).
