# Метод: Robota.ua «водій таксі» → роботодавці, що наймають водіїв

| | |
|---|---|
| Джерело | Robota.ua, публічний JSON-API сайту `api.robota.ua` (пошук вакансій за запитом «водій таксі» по містах) |
| Гіпотеза | Як і з Work.ua: хто наймає водіїв «на авто компанії», той має парк. Частина роботодавців є на обох сайтах |
| Версія | 1.0 (2026-11-17) |
| Файли | `collector.js` (збір у браузері), `merge.py` (злиття в реєстр) |
| Сирі дані | `prospecting/_raw/<YYYY-MM-DD>_robotaua-vodiy-taksi.json` |

## Як працює
1. **Скан.** `GET api.robota.ua/vacancy/search?keyWords=водій таксі&cityId=<id>&page=N&count=40`, з кожної відповіді беремо
   тільки документи з `cityId` свого міста (пошук підмішує сусідні міста).
2. **Вакансія.** `GET api.robota.ua/vacancy?id=<id>`: опис, контактна особа (ім'я), ознака кадрової агенції (`isAgency`), адреса.
3. **Компанія** (`notebookId`): `GET api.robota.ua/company/<id>` (назва, `countEmployeeId`, сайт, опис) і
   `GET api.robota.ua/company/<id>/vacancies?page=0&count=1` (поле `total` дає кількість вакансій компанії).
   ⚠️ `vacancy/search?notebookId=` фільтр ігнорує й віддає total усього сайту (~100 тис.), тому його не використовувати.
4. **Злиття** (`merge.py`).

**Розмір компанії** (`countEmployeeId`, розшифровано на сторінках `robota.ua/company<id>` 2026-11-17):

| код | розмір |
|---|---|
| 0 | не вказано |
| 1 | до 20 |
| 2 | 20–50 |
| 5 | 50–100 |
| 3 | 100–250 |
| 6 | 250–500 |
| 4 | понад 500 |

**ID міст**: з `ua-api.robota.ua/dictionary/cities-with-regions` (див. `CONFIG.cities` у `collector.js`).

## Як відтворити
1. Відкрити https://robota.ua/ у Chrome.
2. Виконати `collector.js` у консолі сторінки, далі `g24rua.start()`. Опитувати `g24rua.status()` до `done: true` (≈5 хв).
   Сайт може сам перейти на іншу сторінку (SPA). Стан при цьому зберігається, доки сторінку не перезавантажено.
3. `g24rua.stage()` → Ctrl+C → у PowerShell з папки `! marketing`:
   `Get-Clipboard -Raw | Out-File -Encoding utf8 "prospecting/_raw/<YYYY-MM-DD>_robotaua-vodiy-taksi.json"`.
4. `python -I prospecting/methods/robotaua-vodiy-taksi/merge.py <файл> --dry-run`, потім без `--dry-run`.
5. Рядок в «Історію прогонів» і в журнал `prospecting/sources.md`.

## Правила відбору
Ті самі, що в [workua-vodiy-taksi](../workua-vodiy-taksi/method.md): **реєстр один, нікого не відсіюємо**.
- Ключ `robotaua:<notebookId>` (без компанії: `robotaua-job:<vacancy_id>`).
- C (орієнтир): авто > 15, від 50 співробітників, > 20 вакансій, кадрова агенція, служба таксі з водіями на власних
  авто або взагалі не таксі. A: 2–15 авто, ФОП/ФЛП. B: решта (на Robota.ua найменший розмір «до 20», тож за розміром
  A не ставимо).
- **Уже в реєстрі** → `де_рекламується` += `Robota.ua (міста)`, відмітка з датою в нотатках, порожню `контактна_особа`
  заповнюємо. Та сама назва склеюється, якщо збігається місто **або** наявний запис теж компанія з сайту вакансій
  (`workua:`/`robotaua:`): мережі на кшталт DriveMe в різних містах — це одна компанія. Інакше (наприклад, ім'я з OLX)
  ставимо «можливо той самий».
- Гіпотеза «не перевірено» (AI-список), знайдена тут, отримує стадію «перевірено».
- 🚩 Полтава + Володимир/Владимир у назві, контактній особі чи тексті.

## Обмеження
- Телефон контактної особи (з 1.1) API віддає відкрито, беремо його і номери з тексту опису.
- Склейка тільки за точною назвою (без ТОВ/ФОП/лапок). «Гордієнко М.В.» і «Гордієнко М. В.» склеїлись, але інші
  варіанти написання можуть не склеїтися.
- «N авто» витягується з тексту, тож можливі хибні числа.
- Херсон: 0 вакансій на 2026-11-17.
