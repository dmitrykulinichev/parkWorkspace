# Метод: каталог Uklon «Пропозиції автопарків»

| | |
|---|---|
| Джерело | https://fleet-drivers.uklon.com.ua — офіційний сайт Uklon (Wix), де парки-партнери публікують вакансії для водіїв |
| Гіпотеза | Парки, які платять Uklon за розміщення вакансій, — активні партнери Uklon, що ростуть (шукають водіїв) |
| Версія | 1.0 (2026-11-18) |
| Файли | `collect.py`, `merge.py` |
| Сирі дані | `_raw/<дата>_uklon-fleets.json` |

## Як працює
1. `collect.py` читає головну сторінку каталогу, знаходить усі посилання `/vakansiyi/<slug>` і завантажує кожну сторінку
   (пауза 1 с). Зберігає назву, очищений текст (умови, авто, графік, вимоги), телефони й зовнішні посилання, якщо є.
   Форму заявки на сторінці НЕ заповнюємо.
2. `merge.py`: ключ `uklonfleet:<slug>`; бренд = назва без міста; склейка: ключ → бренд → входження бренду в назву
   (≥ 5 літер). Мережа (бренд на ≥ 3 сторінках або вже C) → C; новий парк → B «парк-партнер Uklon (каталог)».
   Відомим дописуємо «Uklon каталог автопарків (місто)».

## Як відтворити
```
python -I prospecting/methods/uklon-fleets/collect.py prospecting/_raw/<YYYY-MM-DD>_uklon-fleets.json
python -I prospecting/methods/uklon-fleets/merge.py   prospecting/_raw/<YYYY-MM-DD>_uklon-fleets.json --dry-run
```

## Обмеження
- Телефонів і сайтів на сторінках немає (лише форма заявки), місто вказане не завжди.
- Каталог невеликий (≈ 50 вакансій), але це парки, які активно працюють з Uklon. Плюс він корисний для розмови про партнерство з Uklon.
- Апостроф у slug («кам'янське») приходить як `&#x27;`; у v1.0 це виправлено, інакше 404.
