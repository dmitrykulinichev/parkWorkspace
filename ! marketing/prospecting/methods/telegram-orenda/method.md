# Метод: Telegram — канали парків і групи/дошки «оренда авто під таксі»

| | |
|---|---|
| Джерело | Telegram: глобальний пошук у web.telegram.org (акаунт власника g24) + публічні сторінки `t.me/s/<username>` |
| Гіпотеза | Малі й середні парки ведуть свої канали («оренда авто під таксі Київ»), а дрібні власники пишуть «здам авто» в міських групах і каналах-дошках |
| Версія | 1.0 (2026-11-17) |
| Файли | `discover.js` (пошук чатів у Telegram Web), `parse_tme.py` (читання t.me без логіна), `merge.py` (злиття), `telegram_places.csv` (майданчики) |
| Сирі дані | `_raw/<дата>_telegram-discover.json`, `_raw/<дата>_telegram-tme.json` |

## Як працює
1. **Пошук чатів** (`discover.js`, у залогіненому web.telegram.org/k). Для кожного запиту з `QUERIES` (загальні + «оренда авто <місто>»
   укр/рос + «таксі <місто>») вводимо текст у поле пошуку, натискаємо «show more» у блоці Global search, зчитуємо рядки:
   peer-id, назва, @username, кількість учасників (група) чи підписників (канал). **Тільки читання**: нічого не пишемо,
   ні на що не підписуємось.
2. **Вміст** (`parse_tme.py`, без логіна): `https://t.me/s/<username>` — опис і останні ~20 постів каналу; для груп
   `https://t.me/<username>` (назва, опис, учасники; повідомлення груп без логіна не видно). Витягуємо телефони
   (+380…), @контакти, посилання, згадані міста України; позначаємо іноземні (Москва, Польща… і жодного міста України).
3. **Злиття** (`merge.py`):
   - іноземні і «не про оренду авто» → лише `seen.csv`;
   - **майданчик** = група або канал-дошка (≥ 4 різних телефонів у постах, тобто пишуть різні власники) → `telegram_places.csv`.
     Телефони з його постів, що збігаються з реєстром, дописуються власнику в `де_рекламується` як `Telegram (@майданчик)`;
   - **канал парку** → лід `tg:<username>`; склейка за телефоном, потім за назвою; пріоритет C (> 15 авто), A (2–15), B (невідомо).

## Як відтворити
1. web.telegram.org/k у Chrome із залогіненим акаунтом → виконати `discover.js` у консолі → `g24tg.start()` (≈7 хв на 83 запити)
   → `g24tg.status()` до `done` → `g24tg.stage()` → Ctrl+C → `Get-Clipboard -Raw | Out-File -Encoding utf8 prospecting/_raw/<дата>_telegram-discover.json`.
2. `python -I prospecting/methods/telegram-orenda/parse_tme.py prospecting/_raw/<дата>_telegram-discover.json prospecting/_raw/<дата>_telegram-tme.json` (≈6 хв).
3. `python -I prospecting/methods/telegram-orenda/merge.py prospecting/_raw/<дата>_telegram-tme.json --dry-run`, потім без `--dry-run`.

4. **Повідомлення майданчиків** (`read_groups.js`, у залогіненому web.telegram, тільки читання): перед запуском **один раз клікнути
   в поле пошуку**, далі `g24tgr.start([usernames], {days: 90, maxScrolls: 30})`. Скрипт відкриває чат як превʼю (JOIN не натискаємо),
   спершу прокручує до найновіших (Telegram відкриває чат на місці, де його лишили), потім вгору до межі `days`, накопичуючи повідомлення.
   `stage()` → `_raw/<дата>_telegram-groups.json` → `merge_groups.py` (автори оголошень за телефоном → реєстр, відмітка майданчика).

## Обмеження
- Глобальний пошук Telegram шукає за **назвою/username** чату і віддає ~10 результатів на запит, тому багато запитів міст дають 0
  (перевірено вручну: «аренда авто Полтава» справді порожній). Розширювати — новими формулюваннями в `QUERIES`.
- **Повідомлення груп** без логіна не читаються: власників, які пишуть «здам авто» в групах, цей метод поки не витягає.
  Наступний крок (v1.1): читати останні повідомлення груп з `telegram_places.csv` у web.telegram (тільки читання).
- Пошук підмішує іноземні чати (Москва, Польща): фільтр за містами в `parse_tme.py`.
