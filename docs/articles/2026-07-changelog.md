# Що нового: липень 2026

## Список автомобілів парку для персоналу

У мобільному застосунку в режимі персоналу з'явилася повноцінна сторінка автомобілів парку. Одразу видно які авто зайняті і хто за кермом, а які вільні. Тап по автомобілю відкриває деталі: рік, колір, тип кузова, паливо, пробіг, статус, водій.

Для зручного пошуку — рядок фільтрації і кнопка фільтра: можна відокремити зайняті від вільних або вибрати конкретну марку та модель. Якщо фільтр активний — іконка підсвічується крапкою.
