# Відеоролики застосунку водія

Ролики для водіїв (мануал) і лендінгу. План серії — `workspace/plans/driver-videos-plan.md`.

## Як влаштовано

Один ролик — одна тека (`02-pochatok-zminy/` …). Єдине джерело — **`scenario.yaml`**:

- `vars` — змінні (герой, парк, авто, номер); в тексті й діях — `{model}`, `{plate}` …;
- `steps` — кроки: `id`, `screen` (що в кадрі), `say` (озвучка), `do` (дії — **за текстом на екрані**, не
  координатами: після зміни дизайну ролик перезаписується тією самою командою, правити треба лише крок, де
  змінився текст кнопки). Дії: `tapOn` (текст або `{text, index}`), `extendedWaitUntil: {visible, timeout}`,
  `eraseText: N`, `inputText` (латиниця й цифри), `wait: мс`, `launchApp`;
- пауза після кроку рахується з довжини озвучки (`wordsPerSecond`, `tailSeconds`) або `hold` у кроці.

Інший ролик — скопіювати теку й змінити змінні та кроки.

## Що генерується

| Файл | Що це |
|---|---|
| `scenario.md` | **сценарій** — для погодження: кроки, озвучка, оцінка хронометражу (`build.mjs plan`) |
| `out/timing.md` | **факт зйомки** — реальні таймкоди дубля й чи встигає диктор |
| `out/subtitles.srt` | ті самі таймкоди — субтитри / доріжка для монтажу озвучки |
| `out/voice.m4a`, `out/video-voice.mp4` | озвучка (голос Леся, macOS) на таймкодах і ролик з нею |
| `out/video.mp4` | ролик, обрізаний від першого до останнього кроку |
| `raw/take-N.mp4`, `raw/take-N.run.json` | сирі дублі й журнал кроків і тапів (не в git) |

## Запис

```sh
cd workspace/video/tools && npm install      # раз
node reset.mjs                               # герой без авто (здати, якщо прийняте)
./record.sh 02-pochatok-zminy                # сценарій → запис → факт зйомки → озвучка → out/video-voice.mp4
```

Виконавець кроків — `tools/device.mjs` (не Maestro): кнопку знаходить `uiautomator dump`, тисне `adb` з
тривалістю ~0,3 с, тож Android показує дотик кружечком ("Показувати дотики" вмикає й вимикає `record.sh`);
час і точка кожного тапу — у `out/timing.md`. Озвучка — `tools/voice.mjs` (інший голос: `VOICE=…`).

Перед записом — стан даних з розділу «Підготовка кадру» в `scenario.md` (напр. герой без авто).
Емулятор `Medium_Phone`, Гараж — релізна збірка; вхід героєм робить людина (паролі — не в файлах).
