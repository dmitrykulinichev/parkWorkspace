### 2026-11-05 · В1 «Як почати»: факти → чернетка

**Факти з коду** (kmp 2.0.24: `ui/login`, `ui/register/RegisterViewModel.kt`, `ui/forgot`, `ui/joinpark`,
`composeResources/values/strings.xml`; бекенд `DriverInviteService`, `Park::joinCodeFor`):
- Реєстрація — 6 кроків: код парку → телефон + SMS → «Ваші дані» → посвідчення → email (можна «Пропустити»)
  → пароль (≥ 8 символів). Після коду парку показується «Парк: …», для коду від колеги — «Вас запросив(-ла): …».
- Код від колеги — `<код парку>-<реферальний код>` (той самий, що «Поділитися додатком»).
- Вхід — «Телефон або email» + «Пароль»; відновлення — телефон або email → SMS-код → «Зберегти й увійти».
- Сесія без парку → екран «Код парку» / «Приєднатися».
- Після входу: дозволи (геолокація для SOS, сповіщення SOS, камера для QR), пропозиція «Підключити Telegram»
  (лише якщо в парку є бот), «Знайшли вас в Uklon» (якщо парк уже додав водія в Uklon).
- Парк може сам створити водія й задати пароль (кабінет: Водії → ⋮ → «Встановити пароль») — тоді лише вхід.

**Чернетка:** `guides/driver/01-yak-pochaty.md`, місця для роликів R, 0, 1 — коментарями.

**Перевірити наживо (емулятор, «Київ»):** чи приходить SMS (раніше крок чекав Firebase), порядок вікон після
реєстрації (дозволи → Telegram → Uklon), лист для відновлення через email. Не описано свідомо: «Знайшли вас в
Uklon» (водію нічого робити не треба) — на розбір.

**Рішення.** Документацію одразу супроводжуємо живими скрінами (стадія «Чернетка з живими скрінами»); по ходу
покращуємо й сам лендінг. Записано в правила й рішення `guides/README.md`.

### 2026-11-05 · В1: живі скріни, тестування

**Рішення користувача.** Сторінку робимо одразу публікаційною (заливає й дивиться готовий варіант); пишемо
документацію й водночас тестуємо; дрібні дефекти — одразу; основна мова розробки сторінок — українська.

Емулятор `Medium_Phone` був без Garage24 (стояв сторонній `com.multireader`) — встановлено релізну 2.0.24 (204)
з `kmp/androidApp/build/outputs/apk/release/`. Мова застосунку до входу — мова телефона; для знімання —
`cmd locale set-app-locales`. Код «Київ» `WP7FR2` діє на бойовому бекенді (крок лише перевіряє код).

**Знахідки тестування В1:**
1. en: заголовок «Sign in», кнопка «Enter» — різні слова для однієї дії.
2. Після коду парку майстер одразу йде на телефон: назву парку («Парк: Київ») водій не бачить, лише якщо
   повернеться назад. Чернетку виправити: не обіцяти, що назва з'явиться.
3. Системне «назад» Android на кроці майстра не повертає на попередній крок (лише стрілка в застосунку).
4. Одразу після запуску на мить з'являється банер «Не вдається з'єднатися з сервером».

**Ще рішення користувача.** Два шляхи доступу: самостійна реєстрація і водій, якого парк уже додав. Ідея —
селектор мови прямо на першому екрані.
Перевірено кодом бекенду (`DriverAuthController::resetPasswordWithPhone`): водій, якого додав парк, сам ставить
пароль через «Забули пароль?» за SMS (шукає користувача за телефоном); або пароль задає парк у кабінеті.

**Виправлено в застосунку (kmp, у сторах — з наступним релізом):**
- системне «назад» у майстрах входу — `PlatformBackHandler` у спільному `AuthStepScaffold` (реєстрація,
  відновлення пароля);
- «✓ Парк: …» тепер і на кроці телефона — `ParkConfirmed` (`RegisterFlow.kt`);
- en: кнопка входу «Enter» → «Sign in»;
- вибір мови на екрані входу — `LanguagePicker` у `LoginScreen.kt`, те саме налаштування, що «Налаштування →
  Мова»; назви мов — одне місце `ui/common/LanguageLabel.kt` (і для налаштувань).
Перевірено на емуляторі (локальна релізна збірка 2.0.24): мова перемикається одразу, «назад» повертає на вхід.
Банер «немає зв'язку» одразу після запуску — не виправляв (на мить, сам зникає; записати в план застосунку).

**Лендінг:**
- `/docs/driver-start` — `content/docs2/driver/start.md`, група «Застосунок для водія» першою в `menu.json`;
- скріни з реєстру в документації: `![](screen:id)` → `Docs2Controller::renderRegistryScreens` (через
  `partials.screen`, без `<p>` навколо `<figure>`), `og:image` зі `screen:` — шлях з реєстру;
- мапа сайту: скріни сторінок документації з реєстру (`pages: /docs/<slug>`);
- тести: `screen:` у документації — у реєстрі й у `pages` (26 тестів, зелені);
- посилання в тексті документації й блогу не мали стилю — `.content a:not([class])` (картки «попередня /
  наступна» блогу не зачеплено).
Чернетку `guides/driver/01-yak-pochaty.md` прибрано — джерело тепер сторінка на лендінгу. Сценарій знімання —
