## Чернетка структури (за зразком)

1. Що зробите: зняти стан авто фото й/або відео, щоб парк бачив, у якому стані ви його взяли чи здали.
2. Потік «Фото»: «+» → «Фотозвіт» → «Зробити фото» (до 10) → мініатюри (видалити / перезняти) → коментар → «Зберегти».
3. Потік «Відео»: «Записати відео (до 1 хв)» → запис → обробка → плитка: «Переглянути» / «Перезаписати» / «Видалити».
   Можна разом із фото.
4. Без інтернету: звіт і файли чекають на телефоні, надсилаються самі; стан — «Мої записи» → «Фотозвіти».
5. Змінити коментар / видалити — 12 год, поки парк не переглянув.
6. «Не виходить»: немає доступу до камери, «Не вдалося підготувати відео», «… не прийнято».
