# Вхід у застосунок за телефоном (phone-first)

**Мета:** водій не обирає сценарій. Перший екран — номер телефону → SMS; бекенд сам вирішує: акаунт є (зареєструвався
або його додав парк) — вхід; немає — реєстрація (код парку → дані → посвідчення → email → пароль).
Знайдено під час написання документації «Як почати» (`tasks/2026-11-05-docs-v2-driver`).

## Рішення (погоджено 05.11.2026)

- Вхід за підтвердженим телефоном без пароля; пароль — необов'язковий шлях «Увійти з паролем» (телефон/email).
- До SMS не розкриваємо, чи є акаунт (перебір номерів неможливий).
- За замовчуванням (питання користувачу відкрите): після входу через SMS пароль не просимо; у реєстрації крок
  пароля поки лишається як є.
- Стара версія A не змінюється: наявні запити бекенду не чіпаємо, лише новий.
