# Не баг (UX): у формі слота «Графіка роботи» — водії всіх доступних парків

Знайдено 2026-11-11 на проді: кабінет парку «Київ» (park 15) → «Графік роботи» → «+» у клітинці → «Створити
слот» → список «Водій» містить водіїв DiDiDrive/DiDiDrive2 (Батрак Андрей, Байдак Олександр, Безима Юрій…), а не
лише 11 водіїв «Києва» (у «стакані» праворуч — 11, правильно). Перед тим та сама сторінка після перемикання парку
показувала графік DiDiDrive під шапкою «Київ», доки не перезавантажили (кеш попереднього парку).

Що перевірити: звідки форма слота бере водіїв (запит без парку / без ParkScope / кеш React Query без park_id у
ключі) і чи можна так призначити чужого водія на авто «Києва». Це витік персональних даних між парками.

## Висновок 2026-11-11

Не витік: «Графік роботи» мультипарковий за задумом — показує всі парки й водіїв, до яких користувач має доступ
(`DriverScheduleService::getOptions` → `accessibleParkIds`). Призначити водія іншого парку на авто бекенд не дасть
(`StoreDriverScheduleSlotRequest`: парк водія = парк авто). Лишається UX: у формі слота фільтрувати «Водій» за
парком вибраного авто, щоб не пропонувати тих, кого все одно не можна обрати.
