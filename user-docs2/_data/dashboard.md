# Головна
> `page:dashboard` · `/`

Головна панель: огляд ключових показників вашого автопарку, стану ТО, задач та фінансової активності Uklon.

| `sec:dashboard-vehicle-status` | Статус авто: поточний стан завантаженості та доступності вашого автопарку. |
| `sec:dashboard-maintenance` | Критичне обслуговування: автомобілі, що потребують термінового ТО. |

| `sec:dashboard-tasks` | Активні задачі: ваші поточні справи та пріоритетні завдання. |
