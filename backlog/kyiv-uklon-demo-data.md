# Тестові дані Уклону для парку «Київ»

_Записано 2026-10-29 під час статей блогу._

Парк «Київ» (id 15) — демо-парк для статей, документації й роликів — не підключений до Уклону. Через це
частина кабінету в ньому порожня або з попередженням і не годиться для скрінів:

- «Заробіток водіїв» — «Не вдалося отримати дані з Uklon… Uklon settings not found», колонки Уклону з
  прочерками. Звіт вивірений — **код не чіпати**, проблема лише в даних.
- «Знайти в Уклоні» у формах водія й авто — «Знайдено 0» (немає флоту).
- Економіка парку/авто, бонуси брендування, замовлення — без даних Уклону.

Треба придумати, як наповнити «Київ» правдоподібними даними Уклону (вигадані водії, авто, замовлення,
заробіток) без реального акаунта Уклону і без доступу до DiDiDrive. Варіанти — обговорити:
сідер/data-міграція з демо-рядками в архівній базі Уклону; «демо-режим» налаштувань Уклону для парку.
