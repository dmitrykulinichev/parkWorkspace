# Техборг: спростити підключення Telegram-бота й групи для парку

Записано 2026-11-06 на прохання власника — після того, як він сам підключав бота й групу для тестового
парку «Київ» (для документації й входу з кодом у Telegram): «дуже складно… для нового парку».

## Як зараз (що довелося пройти)

1. Створити бота в @BotFather, скопіювати токен і назву → вставити в кабінет («Інтеграція Telegram»).
2. Створити групу, додати бота.
3. Зробити групу супергрупою — у Telegram для цього немає кнопки: треба знати, що це стається «саме», якщо
   увімкнути «Історію чату для нових учасників: Видима» або зробити групу публічною. Перемикач зберігається
   без кнопки «Зберегти» — незрозуміло, чи спрацювало.
4. Дізнатися ID групи: пересилання боту @RawDataBot показує ID автора, а не групи; треба «Відповісти в іншому
   чаті» або додати сторонній бот у групу. Після перетворення ID змінюється (`-100…` з іншими цифрами) — старий
   перестає працювати, дописати `100` до старого не можна.
5. Вставити ID в кабінет; зробити бота адміністратором (інакше не бачить повідомлень і не ставить реакції).
6. Не залишити групу публічною (власник зробив її публічною, щоб перетворити, — і забув би повернути).

Уже є: перевірка з'єднання в налаштуваннях (`ParkSettingsController`) повідомляє новий ID після перетворення
(`migrate_to_chat_id`) і вгадує ID супергрупи без префікса `-100`.

## Що зробити (ідеї, обговорити)

- **Без ID вручну:** бот сам бачить, що його додали в групу (`my_chat_member` у вебхуку), і кабінет показує «Бот
  у групі «…» — підключити?». ID, назва, тип — з Telegram, людина нічого не копіює.
- **Перетворення на супергрупу — автоматично:** вебхук отримує `migrate_to_chat_id` і сам оновлює ID в
  налаштуваннях парку (зараз лише підказує при ручній перевірці).
- **Права бота — перевіряти й показувати:** `getChatMember` → «бот не адміністратор: [як призначити]»;
  попередження, якщо група публічна.
- **Майстер у кабінеті** замість полів: крок 1 — токен від BotFather (з посиланням і картинкою), крок 2 —
  «додайте бота в групу» (кнопка-посилання `t.me/<бот>?startgroup=…` відкриває вибір групи й одразу додає бота),
  крок 3 — статус: група знайдена, супергрупа, бот адмін ✓.
- Оцінити: чи можна обійтись без власного бота парку (спільний бот платформи) — тоді крок BotFather зникає;
  мінус — водії бачать не бренд парку. Рішення — за власником.

## Пов'язане

- Вхід за телефоном з кодом у Telegram (`workspace/tasks/2026-11-05-phone-first-login`).
- Документація: сторінка В6 «Як писати в групу Telegram» і (для персоналу) підключення бота — коли спростимо,
  описати вже простий шлях.
